================================================================================
分析
================================================================================

1. opus 5/5 全过, haiku 4/5 — Basic 级别区分度不够大
   → 需要 Intermediate/Advanced 级别才能拉开差距
   → 这符合 VGV 论文的发现 (Basic 级别闭源模型都很强)

2. haiku 的 Toffoli 错误很有代表性:
   - 视觉识别正确 (知道是双控制门)
   - 但 API 知识不准确 (用了不存在的 .toffoli() 方法)
   → 说明视觉理解和代码生成是两个独立能力
   → 这是论文可以讨论的点

3. 两个模型都能正确识别:
   - H 门的方块符号
   - CNOT 的控制点 (●) 和目标 (⊕)
   - 多 qubit 线的从上到下编号
   - 门的从左到右顺序

4. 成本对比:
   opus: 0.24 credits/次, 100% pass
   haiku: 0.04 credits/次, 80% pass (6x 便宜, 但有 API 错误)
