[0m[38;5;10mfrom braket.circuits import Circuit

# 3-qubit Grover's algorithm
circuit = Circuit()

# 初始叠加
circuit.h([0, 1, 2])

# Oracle (标记目标态 |11>)
circuit.h(2)
circuit.ccnot(0, 1, 2)  # Toffoli: q0,q1 控制, q2 目标
circuit.h(2)

# Diffusion operator
circuit.h([0, 1, 2])
circuit.x([0, 1, 2])
circuit.h(2)
circuit.ccnot(0, 1, 2)  # Toffoli: q0,q1 控制, q2 目标
circuit.h(2)
circuit.x([0, 1, 2])
circuit.h([0, 1, 2])

print(circuit)
[0m[0m[0m
[0m[0m
这段代码实现了一轮 3-qubit Grover 搜索，Oracle 标记的是 |11⟩ 态（在 q0、q1 上）。两个 Toffoli 门分别出现在 Oracle 和 Diffusion 算子中，q2 作为辅助比特参与相位翻转。[0m[0m
